# Модель безопасности

## Доверие

Это персональный MVP для доверенного Mac и его владельца. Backend и локальная конфигурация агента доверены; LLM-ответ, транскрипция, имена файлов и все сетевые payload недоверены. DeepSeek не получает shell или AppleScript. Компрометация ОС/терминала, браузерного origin или bootstrap-секрета выходит за пределы изоляции приложения.

## Авторизация

Создание identity Mac требует 256-битного bootstrap-секрета. Повторная выдача pairing-кода требует токена Mac. Восьмизначный криптографически случайный код живёт до 5 минут, одноразовый; на endpoint 5 попыток в минуту/IP. Pair complete — единственный анонимный API авторизации, защищён знанием кода и rate limit. `/health` отдаёт только статус. Статические файлы UI публичны; все данные, команды, конфигурация и оба WS защищены токеном.

Сервер сохраняет SHA-256 хеши случайных 256-битных токенов, а не исходные токены. Токен телефона — HttpOnly, SameSite=Strict, Secure при HTTPS. Срок cookie 90 дней; серверные identity действуют до отзыва. Токен Mac — локальный файл 0600. Токены не передаются в query string WebSocket. Браузерный WS требует разрешённого Origin; cookie POST/PUT/DELETE также проверяют Origin. Чужой Origin отклоняется даже при правильной cookie.

Любой телефон данного личного пространства может редактировать реестр и отзывать связанные устройства. Подтверждать/уточнять команду может только создавшая её identity. Отзыв Mac отзывает также его телефоны. При утрате bootstrap-секрета замените его и отзовите неизвестные identity.

## Исполнение

- Strict Zod union запрещает неизвестные действия и параметры; LLM-вывод парсится JSON, не eval.
- execFile/spawn получают массив аргументов, shell выключен. AppleScript-исходники фиксированы; имя приложения передаётся через argv и имеет ограниченный алфавит.
- Реестр телефона не может добавлять исполняемые команды, менять ALLOWED_DIRECTORIES или agent-trust.json.
- Пути требуют абсолютного адреса, realpath и принадлежности разрешённому корню с проверкой границ. Симлинки наружу, скрытые компоненты, .app/.workflow/.scptd запрещены.
- Для файлов разрешены только перечисленные расширения документов/медиа. Содержимое документов не анализируется: вредоносные PDF/документы по-прежнему обрабатывает соответствующее приложение macOS. Выбирайте доверенные папки.
- URL: только http/https, без userinfo. Это не репутационная проверка сайтов.
- Закрытие приложений, блокировка, screenshots, Music, Shortcuts и сценарии требуют подтверждения на сервере и агенте. Модель может запросить дополнительное подтверждение, но не снять обязательное.
- TTL максимум 60 секунд. Агент сначала атомарно записывает execution ID, затем запускает действие. Повторы и просроченные команды отклоняются, в том числе после перезапуска.

Проверка realpath перед `open` не является sandbox ядра ОС: локальный злоумышленник, способный менять разрешённый каталог в момент открытия, может устроить TOCTOU-гонку. Не предоставляйте такие каталоги недоверенным процессам.

## Локальные сценарии и Shortcuts

Только владелец Mac может править `agent-trust.json`. Эти заранее настроенные программы и Shortcuts имеют права пользователя macOS. Проверка их содержимого и разрешений — локальная граница доверия, а не задача LLM. Не добавляйте действия для отправки сообщений, чтения секретов, покупки, удаления и других запрещённых возможностей. Удалённый реестр может выбрать только уже существующий ID, а каждая попытка требует подтверждения.

## Приватность и сеть

Аудио обрабатывается локальным Whisper и удаляется; DeepSeek получает транскрипцию, контекст, имена и пути реестра/результатов поиска. Содержимое документов и снимки экрана не отправляются. Снимки остаются в `data/screenshots`, маршрут их скачивания отсутствует. База не шифруется самим приложением; используйте FileVault и защищайте резервные копии.

Для телефона и удалённого агента используйте HTTPS/WSS, точные origins и Secure-cookie. Не публикуйте Vite и не меняйте политику origin на `*`. HTTP агента разрешён только через localhost. Сервис не является удалённой оболочкой или средством администрирования чужих устройств.

Команда не ставится в офлайн-очередь. Отмена после dispatch невозможна. Потерянный ответ не означает, что действие не произошло: проверьте Mac перед новым запросом. Принудительное завершение процесса может оставить временное аудио в OS temp; обычные ошибки/отмена очищаются в finally.

## Проверки

Автотесты покрывают строгую схему, URL, TTL, replay после перезапуска, подтверждения, неизвестные ID, traversal/symlink/prefix escape, pairing/expiry/revocation, auth/Origin/ownership, WebSocket handshake/lifecycle и команду через mock Mac. Это проверка заявленной политики, не внешний security-аудит.
