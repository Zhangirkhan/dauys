# Чеклист проверки на Windows 11 x64 VM

Ветка: `Windows`
Артефакт: `dist/windows-installer/DauysSetup-x64.exe`  
Сборка на Windows: `pnpm build:agent:windows-installer`

**Не называть готову к merge, пока этот список не пройден на настоящей Windows.**

## Подготовка VM

- [ ] Чистая Windows 11 x64 без Node.js / pnpm
- [ ] Обычная учётка без прав администратора
- [ ] Доступ к https://dauys.esl.kz (или тестовому стенду)
- [ ] Bootstrap-секрет тестового/prod стенда (не коммитить)
